## ✨ Description

Welcome to the **Holographic Omni-Sphere**, Moe Kyaw Aung's interactive developer portfolio. This cutting-edge web application serves as a dynamic showcase of senior mobile architecture and technical leadership, blending immersive 3D visualization with detailed project insights. Navigate through an orbiting 3D sphere representing a network of 16 multi-layered case studies, each offering deep dives into architecture, telemetry, and security protocols.

## 🌟 Features

This portfolio offers a rich, interactive experience to showcase technical prowess:

*   **Interactive 3D Omni-Sphere Canvas** 🌍: A mesmerizing 3D globe with auto-rotation and drag-to-rotate functionality, featuring 16 clickable application nodes representing individual project case studies.
*   **16 Multi-Layer Holographic Case Studies** 🗂️: Each node unveils a detailed, multi-layered report (Schematic, Architecture & Code, Telemetry & Impact, Security & Wards) for various mobile and web applications.
*   **Holographic Sound Effects** 🔊: Engaging audio feedback (beam, node select, layer switch, AI voice, chime) powered by the Web Audio API enhances the futuristic user experience.
*   **AURA Holographic AI Assistant** 🤖: An interactive AI entity providing real-time architectural explanations, startup telemetry, and project insights based on user queries.
*   **Comprehensive Credentials Display** 🏆: Showcases 82+ verified Programming Hub certificates across 8 engineering disciplines, complete with search and category filtering.
*   **Extensive Network Beacons** 📡: Links to 43 GitHub repositories, 38 personal web probes, 20+ direct email channels, and 16 verified social media profiles, demonstrating a broad digital footprint.
*   **Direct Communication Matrix** 📞: Provides immediate access to voice hotlines and encrypted email channels for potential collaborations.
*   **Responsive Holographic UI** ✨: Crafted with Tailwind CSS, ensuring a visually stunning and adaptive interface across all devices.
*   **Animated Typist Headline** ✍️: Dynamic text animation highlighting key skills and achievements.

## 🛠️ Installation

To get a local copy up and running, follow these simple steps.

### Prerequisites

Ensure you have the following installed on your system:

*   [Node.js](https://nodejs.org/en/) (LTS version recommended)
*   [npm](https://www.npmjs.com/) (usually comes with Node.js) or [Yarn](https://yarnpkg.com/)

### Clone the repository

```bash
git clone https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-137.git
cd moekyawaung-developer-portfolio-137
```

### Install dependencies

Using npm:
```bash
npm install
```

Or using Yarn:
```bash
yarn install
```

## 💡 Usage

This portfolio is designed to be an interactive experience. Here's how to engage with it:

### Local Development

To run the project in development mode with hot-reloading:

```bash
npm run dev
# or
yarn dev
```

Open your browser to the address provided (e.g., `http://localhost:5173`).

### Build for Production

To build the optimized, single-file production-ready bundle:

```bash
npm run build
# or
yarn build
```

This will generate a `dist` directory containing your single HTML file (`index.html`) thanks to `vite-plugin-singlefile`.

### Preview Production Build

To preview the built production bundle locally:

```bash
npm run preview
# or
yarn preview
```

### Interacting with the Portfolio

1.  **Explore the 3D Omni-Sphere** 🌐: Drag the sphere to rotate it and observe the orbiting application nodes. Click on any node to open its detailed holographic case study.
2.  **Dive into Case Studies** 🗂️: Within a case study modal, switch between "Schematic," "Architecture & Code," "Telemetry & Impact," and "Security & Wards" layers to gain comprehensive insights.
3.  **Chat with AURA AI** 🤖: Click the AURA AI beacon (bottom-right) to engage with the holographic AI assistant. Ask questions about architecture, startup metrics, or specific projects.
4.  **Review Credentials** 🏆: Browse through 82+ verified certificates, using the search bar and category filters to find specific expertise.
5.  **Connect** 📞: Utilize the direct voice hotlines, click-to-copy email channels, and various social media links to establish contact.
